# 🌱 AgriVision

AI-powered crop disease screening application.

## Supported crops

- Bell Pepper
- Potato
- Tomato

## Supported languages

- English
- Hindi
- Gujarati

## Model

MobileNetV2 transfer-learning model trained for 15 crop-health classes.

## Features

- Leaf image upload
- AI disease screening
- Model score
- Alternative predictions
- Disease causes
- Symptoms
- Treatment / management
- Prevention
- Multilingual information

## Important

AgriVision is a screening and educational tool.
It does not replace professional agricultural diagnosis.
